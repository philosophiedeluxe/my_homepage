# Server_CSS_3 – SRVR Abyss

Aktueller Stand: **SRVR Abyss V3**

```css
@import url('https://philosophiedeluxe.github.io/my_homepage/Server_CSS_3/jellyfin_custom.css?v=3');
```

## Basis

Die vollständige Oberflächen-, Interaktions- und Responsive-Schicht stammt aus [Abyss for Jellyfin](https://github.com/AumGupta/abyss-jellyfin), veröffentlicht unter der MIT-Lizenz.

```css
@import url('https://cdn.jsdelivr.net/gh/AumGupta/abyss-jellyfin@main/abyss.css');
```

## Lokale Ergänzungen

- `abyss_srvr.css`: SRVR-Logo und kühles Akzentprofil.
- `player_video_safety.css`: bewahrte Player-Ebenen, damit keine Theme-Fläche das Videobild überlagert.
- `REFERENCE_ANALYSIS.md`: Selektor- und Strukturprüfung der Referenzprojekte.
